# SciKG-LLM

SciKG-LLM is an end-to-end pipeline that turns raw low-resource language documents, such as Sorani Kurdish medical text, into a scientific knowledge graph. It covers text cleaning and Unicode normalization, sliding-window chunking, few-shot LLM triple extraction, LaBSE cross-lingual entity alignment and Neo4j graph construction. It also covers confidence scoring and evaluation with precision, recall, F1-score, entity alignment accuracy and graph-quality metrics.

Dataset: The Kurdish Medical Corpus (KMC) is available on Hugging Face and Mendeley Data.
